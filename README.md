# 单电池仪器预约平台

这是一个基于 Next.js + Supabase 的在线预约平台模板，可部署到 Vercel。

## 功能

- 首页显示未来预约
- 按日期查看当天时间段
- 按小时选择开始/结束时间
- 支持单日预约，也支持跨多日长期稳定性测试预约
- 长期预约会自动占用跨越日期内的所有相关小时段
- 防止任意时间段重复预约，包括跨日预约冲突
- 新建预约时设置取消密码
- 首页预约列表支持取消预约
- 可选管理员取消密码，可取消任意预约
- 数据保存在 Supabase PostgreSQL 数据库中

## 本地运行

```bash
npm install
cp .env.example .env.local
npm run dev
```

## 必需环境变量

```bash
SUPABASE_URL=你的 Supabase Project URL
SUPABASE_SECRET_KEY=你的 Supabase Secret key 或 legacy service_role key
```

## 可选环境变量

```bash
ADMIN_CANCEL_CODE=管理员取消密码
```

设置后，管理员可以在取消预约时输入这个密码来取消任意预约。普通用户仍然可以使用自己预约时设置的取消密码取消自己的预约。

## 数据库初始化或升级

进入 Supabase Dashboard → SQL Editor，运行 `db/schema.sql` 中的 SQL。  
如果你已经创建过旧版表，也可以再次运行这份 SQL，它会自动补充 `end_date`、`cancel_code_hash` 字段，并把防重叠规则升级为支持跨多日预约。


## v5 更新说明

本版本修复了部分数据库中 `id` 字段不是 UUID 时，取消预约会误报“预约记录不存在或编号错误”的问题。取消预约现在会优先按预约记录 id 删除；如果 id 类型不匹配，会再根据预约日期、结束日期、起止小时和预约人进行兜底查找。


## v5/v6 修复说明

- 取消预约时不再强制要求预约编号必须是 UUID。部分早期版本或手动创建的 Supabase 表可能使用数字自增 id，旧代码会在真正查询数据库前直接报“预约记录不存在或编号错误”。新版会优先按 id 查询，若 id 类型不匹配，会继续用预约日期、时间、预约人等信息兜底定位预约。
- 取消请求会同时提交预约的日期、开始时间、结束时间、预约人等信息，降低因数据库 id 类型差异造成的取消失败概率。
- 调整了页面初始日期的生成方式，减少 Vercel 服务器时区与浏览器时区不一致导致的 React hydration 警告。
